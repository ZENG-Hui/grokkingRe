```latex
值得进一步讨论层间滑动与层内畸变在稳定极性相中的协同作用。文献\cite{nsr_nwad103} 的补充材料详细比较了以下两种情形：（i）仅施加层间预滑动而不允许原子弛豫——三层 ZrTe$_5$ 的总能量反而升高，即纯粹的刚性层间位移在能量上不利；然而即便在这种未弛豫的构型中，能带分裂与 BCD 已显著出现，说明层间滑动本身足以破缺 $\mathcal{I}$ 并产生非零的量子几何响应。（ii）从弛豫后的极性相 $P_1$ 中提取中间单层的层内畸变构型——该畸变单层也能产生可观测的 BCD，尽管它作为孤立体系并不稳定\cite{Weng2014PRX}。因此，极性相的热力学稳定性依赖于二者的协同：层间滑动提供 $\mathcal{I}$ 破缺的初始驱动力，层内细微原子畸变（交替五边形的扭曲）则通过局域化学键的重新排布提供能量增益以稳定滑动后的构型。这一"触发—稳定"的两步机制与多层体系中表面层优先滑动的趋势密切相关：表面层仅有一侧与邻层发生范德瓦尔斯相互作用，另一侧暴露于真空，因此其层间约束较内层显著减弱，滑动势垒与层内弛豫代价均相应降低，这正是图\ref{fig:chap03-multilayer-sliding-modes}中内层滑动效应逐渐减弱的微观原因。

从电子结构的角度，上述多层中量子几何响应的强度还与 ZrTe$_5$ 的拓扑性质有内在联系。如前文（第\ref{sec:berry-curvature-nonlinear-hall}节 KME 讨论部分）所述，$K_{xz}$ 主要由轨道磁矩主导，自旋贡献可忽略\cite{Osumi2021kineticTI}。文献\cite{nsr_nwad103} 的补充材料进一步表明，这种大轨道磁矩源于 ZrTe$_5$ 的非平庸拓扑性质：块体 ZrTe$_5$ 位于弱拓扑绝缘体与强拓扑绝缘体的相变点附近\cite{PhysRevLett.117.237601}，其 (010) 表面存在拓扑狄拉克表面态。当薄膜从块体减薄至三层时，上下表面的拓扑态耦合并打开能隙，形成大质量狄拉克色散\cite{PhysRevB.81.041307}，使体系进入二维拓扑绝缘体相\cite{Weng2014PRX, PhysRevX.6.021017}。这种源于拓扑表面态的大质量狄拉克能带仍然携带显著的轨道磁矩，因而在 $\mathcal{I}$ 被滑动破缺后能产生大的 KME。这一拓扑起源也为理解多层薄膜中响应量级的层数依赖性提供了额外线索：随着层数增加，拓扑表面态的杂化减弱、能隙减小，量子几何分布的细节可能随之改变。

```

```latex
\section{小结与展望}
\label{sec:weak-field-summary}

本章围绕"弱场量子几何响应"这一主题，系统讨论了两条具有代表性的二阶横向输运机制链——贝里曲率偶极子（BCD）驱动的非线性反常霍尔效应（NAHE）与量子度规相关的本征非线性霍尔效应（INH），并展示其作为材料内部序参量电学读出信号的潜力。这两条机制链分别源自量子几何张量的两个互补成分——贝里曲率与量子度规，但共享一个核心物理图像：微观对称性的破缺在动量空间留下可观测的"几何指纹"，这些指纹通过非线性输运响应被提取为宏观信号。

在第一条机制链中（第\ref{sec:quantum-metric-nonlinear-hall}节），我们以单层反铁磁体 MnS 为平台，揭示了 $\mathcal{PT}$ 对称体系中由量子度规驱动的 INH 效应\cite{PhysRevLett.131.056401}。尽管 $\mathcal{PT}$ 对称严格禁戒了贝里曲率与 BCD，量子度规的贝里联络极化率（BCP）偶极子仍可提供非零的本征非线性霍尔电导。通过 $\Gamma$ 点的有效 $k\cdot p$ 模型与非 $\Gamma$ 点的过倾斜狄拉克锥对模型，我们建立了 INH 电导率随 Néel 矢量方向 $\theta$ 变化的解析关系。该工作的核心贡献在于：（a）将量子度规从基础理论概念推进到可测量的输运信号层面；（b）为二维反铁磁材料的 Néel 矢量提供了一种不依赖中子散射或自旋霍尔磁电阻的全电学探测方案。

在第二条机制链中（第\ref{sec:berry-curvature-nonlinear-hall}节），我们以 ZrTe$_5$ 薄膜为平台，揭示了层间滑动诱导的自发反演对称性破缺及其引起的 NAHE 与 KME\cite{nsr_nwad103}。该工作的独特之处在于将"结构自由度"引入量子几何响应的语境：范德瓦尔斯层间的低能滑动模式（能垒仅几 meV）提供了 $\mathcal{I}$ 破缺的结构来源，同时在动量空间诱导贝里曲率与轨道磁矩的不对称分布。$k\cdot p$ 模型的解析推导（式\ref{eq:chap03-zrte5-model-bcd-kme}）明确建立了滑动位移 $\lambda$ 与 BCD/KME 之间的线性对应关系，揭示了倾斜项 $B_1$ 在生成非互易响应中的主导作用。多层分析进一步表明，自发 $\mathcal{I}$ 破缺并非三层薄膜的特例，而是可推广至不同厚度薄膜与自然解理表面的普遍现象；AFE 与 FE 等多种滑动构型的共存提示了丰富的极性相图。该机制的物理根源与 ZrTe$_5$ 的拓扑性质密切相关：拓扑表面态赋予费米面附近的能带以显著的轨道磁矩，使得 KME 主要由轨道贡献主导。

两条机制链的对比揭示了量子几何框架的统一性与丰富性。BCD 机制作为费米面性质，与弛豫时间 $\tau$ 成正比（$\chi \propto \tau$），对化学势调控高度敏感；INH 机制作为费米海性质，独立于 $\tau$（$\chi \propto \tau^0$），在散射较强的体系中更具鲁棒性。两者在实验中可通过频率依赖关系加以区分，并可能在同一材料平台中竞争或协同。

需要指出本章工作的若干局限性。理论方面，BCD 与 INH 的计算均基于独立粒子近似与弛豫时间近似，未考虑电子关联效应与各向异性散射对非线性输运的修正；多层滑动的能量分析基于零温第一性原理计算，有限温度下的热涨落、畴结构动力学及其对响应信号的影响需进一步研究。实验方面，ZrTe$_5$ 薄膜中滑动铁电性的直接结构表征（如高分辨 STEM）尚未实现，NAHE 信号有待实验验证；MnS 单层的 INH 检测需要制备高质量的二维反铁磁样品，这在当前仍具挑战性。

展望未来，量子几何为"对称性破缺—电子拓扑态—输运响应"的耦合提供了统一语言，值得沿以下方向进一步拓展：
(i) 在更多范德瓦尔斯薄膜与表面体系中系统识别自发对称性破缺的低能结构自由度，并建立其与 BCD/KME 等非互易响应之间的定量对应；
(ii) 在关联、磁性或莫尔超晶格体系中，研究量子度规与贝里曲率在同一平台下对不同非线性响应通道的竞争与协同；
(iii) 将二阶横向响应用于"序参量读出"与"可切换非互易器件"设计，探索其在低功耗存储、逻辑与传感中的潜在应用；
(iv) 发展超越弛豫时间近似的量子输运理论框架（如第四章将讨论的强场量子几何效应），以统一处理弱场与强场极限下的非线性输运。
```
