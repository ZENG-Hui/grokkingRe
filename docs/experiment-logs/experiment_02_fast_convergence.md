# Configuration Adjustment - Experiment 2

## 🎯 问题分析

### 实验1结果（L0=1.0对齐测试）
- ✅ **成功**: Dense和Sparse曲线基本对齐
- ✅ **验证**: 实现正确性已确认
- ❌ **问题**: 收敛非常慢

### 根本原因

**论文配置 vs 您的任务**:

| 方面 | 原论文 | 您的任务 | 影响 |
|------|--------|---------|------|
| **模型规模** | 大型LM (数百万-数十亿参数) | 小型 (~422K参数) | 大模型需要更保守的优化 |
| **任务复杂度** | 自然语言理解 | 模运算 (x+y mod 97) | 简单任务可以快速收敛 |
| **训练数据** | 海量文本 | 4,753个样本 | 小数据集更容易过拟合 |
| **训练目标** | 语言建模 + 电路发现 | 仅电路发现 | 主要关注稀疏性效果 |

### 配置影响分析

| 参数 | 论文设置 | 影响 | 是否与稀疏性直接相关？ |
|------|---------|------|----------------------|
| **RMSNorm** | ✓ | 保留零值语义 | ✅ **是** - 为稀疏性设计 |
| **adam_eps=0.1** | ✓ | 更粗糙的更新 | ❌ **否** - 数值稳定性 |
| **adam_β2=0.95** | ✓ | 更长的动量记忆 | ❌ **否** - 优化策略 |
| **L0 annealing** | ✓ | 逐步引入稀疏 | ✅ **是** - 核心机制 |
| **AbsTopK** | ✓ | 激活稀疏 | ✅ **是** - 稀疏性组件 |
| **Warmup+Cosine** | ✓ | 训练稳定性 | ⚠️ **部分** - 帮助大模型 |

---

## 🔧 调整策略

### 保留的稀疏性相关配置

这些**必须保留**因为直接影响稀疏化：
- ✅ L0退火机制
- ✅ AbsTopK激活稀疏
- ✅ Top-K权重稀疏化
- ✅ Warmup（有助于稳定训练）
- ✅ Cosine decay（平滑LR下降）

### 调整的优化配置

这些**可以调整**因为不直接影响稀疏性：
- 🔄 **RMSNorm → LayerNorm**: 更适合小模型，收敛更快
- 🔄 **adam_eps: 0.1 → 1e-5**: 平衡稳定性和速度
- 🔄 **adam_β2: 0.95 → 0.98**: 恢复原始dense设置

## 📊 新配置（实验2）

### SHARED_CONFIG变更

```python
# 旧配置 (实验1)
"norm_type": "rmsnorm",
"adam_beta2": 0.95,
"adam_eps": 0.1,

# 新配置 (实验2)
"norm_type": "layernorm",  # 更适合小模型
"adam_beta2": 0.98,         # 原始dense设置
"adam_eps": 1e-5,           # 介于1e-8和0.1之间
```

### 保持不变

```python
# 这些有助于训练稳定性，保留
"warmup_ratio": 0.01,
"use_cosine_decay": True,
"grad_clip_rms": 1.0,

# L0配置不变（对齐测试）
"final_L0": 1.0,
"use_activation_sparsity": False,
```
