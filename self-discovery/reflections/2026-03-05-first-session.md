## Lessons learned

### 1. Don't go silent during long operations
I spent too long retrying failed git clones without telling Hui what was happening. Lesson: report failures early, show progress, don't disappear into retry loops.

### 2. How to send real-time progress updates
- My reply text is only delivered **after the entire response finishes** — not useful for progress updates
- `message` tool sends messages **immediately** — confirmed by experiment with Hui
- **Best practice:** Use `message` tool for mid-task updates, keep final reply text minimal
- Pattern: `message("开始做X")` → work → `message("进展/问题")` → work → final reply with result only
